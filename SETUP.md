# 🛠️ GitHub Profile README - Setup Guide

Everything here already lives in the repo. This guide explains the moving parts and the one-time Action runs you need.

---

## 1. Repository basics

Your README only shows on your profile if it lives in a **special repo named exactly after your username**.

- Repo name: **`Anup-Ojha`** (must match your username exactly)
- Visibility: **Public**

## 2. File structure

```
Anup-Ojha/
├── README.md
├── SETUP.md
├── assets/
│   ├── hero.svg          # hand-authored animated terminal (no third-party service)
│   └── stats.svg         # auto-generated stats card (updated by the Action)
├── scripts/
│   └── gen_stats.py      # queries the GitHub API and renders stats.svg
├── game/                 # the "anup.exe" text adventure (linked from the README)
│   ├── start.md
│   ├── backend.md
│   ├── ai.md
│   ├── about.md
│   ├── contact.md
│   └── secret.md
└── .github/
    └── workflows/
        ├── snake.yml     # contribution-snake animation
        └── stats.yml     # regenerates the stats card
```

The path `.github/workflows/` is **required**: GitHub only runs Actions from there.

---

## 3. One-time: allow Actions to write

Both workflows commit back to the repo, so they need write access.

1. Go to **Settings > Actions > General**.
2. Scroll to **Workflow permissions**.
3. Select **Read and write permissions**, then **Save**.

---

## 4. The stats card (self-hosted, no rate limits)

`stats.svg` is generated by **your own** code, not a shared server, so it never returns 503 or 402.

- Workflow: **Update Stats Card** (`.github/workflows/stats.yml`).
- It runs `scripts/gen_stats.py` using the built-in `GITHUB_TOKEN` (no personal token needed).
- The script queries the GitHub GraphQL API for commits, stars, repos, followers, and top languages, then writes a custom animated SVG.

**First run:** go to the **Actions** tab, pick **Update Stats Card**, click **Run workflow**. After ~1 minute the placeholder card is replaced with your real numbers. It then refreshes every 6 hours.

Local test (optional): `ALLOW_MOCK=1 python scripts/gen_stats.py` renders a sample card with fake data.

---

## 5. The snake animation

1. Go to the **Actions** tab.
2. If Actions are disabled, click **"I understand my workflows, enable them"**.
3. Run **Generate Snake Animation** once. It creates an `output` branch with the snake SVG.

After the first run the snake loads in the README and auto-updates every 12 hours.

---

## 6. The text adventure

`game/start.md` is a playable, choose-your-path mini game built entirely from Markdown files that link to each other. It works on github.com with no build step. Start editing at `game/start.md`; add rooms by creating new `.md` files and linking to them.

---

## 7. Widgets that still use free services

- **Streak stats** (`streak-stats.herokuapp.com`): if it ever goes down, swap the host for
  `https://streak-stats.demolab.com/?user=Anup-Ojha&theme=tokyonight&hide_border=false`
- **Activity graph** and **profile-view counter**: hosted, but reliable in practice.

---

## 8. (Optional) Change the theme

The remaining hosted cards use `theme=tokyonight`. Find-and-replace `tokyonight` with `radical`, `dracula`, `catppuccin_mocha`, `github_dark`, `gruvbox`, or `nord`. The activity graph uses `tokyo-night` (with the hyphen). The `hero.svg` and `stats.svg` colours live in their own `<style>` blocks and adapt to light/dark automatically.

---
